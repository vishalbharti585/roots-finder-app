# 🔢 Root Finding Calculator (Web App)

A modern web-based numerical analysis tool to solve nonlinear equations using multiple root-finding algorithms with interactive visualization and method comparison.

## 📌 Features

- 🔍 Solve nonlinear equations using:
  - Bisection Method
  - Secant Method
  - Newton-Raphson Method
  - Regula Falsi Method

- 📊 Interactive Graph Visualization (Plotly)
- 📋 Step-by-step iteration tracking
- 📈 Method comparison (iterations & convergence)
- 🌙 Dark mode toggle
- ⚡ Loading animation
- 🎨 Modern responsive UI

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask  
- **Frontend:** HTML, CSS  
- **Libraries:**  
  - SymPy (equation parsing)  
  - NumPy (numerical computation)  
  - Plotly (interactive graphs)  

---

## 🧠 How It Works

1. User enters a mathematical function (e.g. `x**3 - x - 2`)
2. Selects a numerical method
3. Inputs initial guesses or interval
4. Application computes:
   - Root of equation
   - Iteration steps
   - Graph visualization
5. Optional comparison of all methods
